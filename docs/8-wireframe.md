### 화면 전환

| 액션 | 결과 | 다음 화면 |
|---|---|---|
| 가입하기 (성공) | ✓ 계정 생성 완료 | SCR-02 (로그인) |
| 가입하기 (중복 이메일) | ⚠ 이미 사용 중인 이메일입니다 (409) | SCR-01 (유지) |
| 가입하기 (8자 미만 비밀번호) | ⚠ 비밀번호는 최소 8자 이상이어야 합니다 (400) | SCR-01 (유지) |

### 비즈니스 규칙 반영
- BR-비밀번호 최소 8자: 비밀번호 필드에 "최소 8자" 힌트 표시
- JWT 저장: Zustand 메모리 저장만 사용 (localStorage 미사용)
- 회원가입 성공 후 로그인 화면으로 이동

## 공통 UI 패턴

### 입력 필드 필수/선택 표시
- 필수 필드: 필드명 뒤에 `*` 표시
- 선택 필드: 필드명 뒤에 `(선택)` 표시

### 버튼 상태
- 활성: 일반 버튼 스타일
- 비활성: `(비활성)` 표시, 클릭 불가
- 로딩: `[ ⟳ 처리 중... ]` 표시

### 메시지 표시
- 에러: `⚠ 에러 메시지` (빨강)
- 성공: `✓ 성공 메시지` (초록)
- 정보: `ℹ 정보 메시지` (파랑)

### 확인 대화상자
- 삭제/탈퇴 등 중요 액션 전에 표시
- "확인", "취소" 두 가지 선택지 제공

## 접근성 고려사항

1. 모든 입력 필드에 `<label>` 태그 사용
2. 필수 필드 표시 (`*`) 명확히 표시
3. 에러 메시지 색상뿐만 아니라 텍스트로도 표시
4. 버튼 비활성 상태 명확히 표시
5. 키보드 네비게이션 지원 (Tab 키)
6. 포커스 상태 시각적으로 표시

## 보안 고려사항

1. 비밀번호 필드: 마스킹 처리 (점/별표 표시)
2. JWT 토큰: 메모리(Zustand)에만 저장, localStorage 미사용
3. 페이지 새로고침 시 토큰 소멸 (재로그인 필요)

5. HTTPS 통신만 사용 권장
6. 이메일 변경 불가 (BR-12)

2. 무한 스크롤 또는 페이지네이션 (1차는 전체 목록 표시)
3. 이미지 lazy loading
4. 번들 코드 스플리팅

## 추가 참고사항

### JWT 만료 시나리오
- JWT 토큰 유효시간: 1시간
- 만료 시: 401 Unauthorized 응답
- 응답 인터셉터가 자동으로 authStore 초기화
- 사용자를 SCR-02 (로그인)로 리다이렉트

### 카테고리 삭제 규칙
- 기본 카테고리: 항상 삭제 불가 (403 Forbidden)
- 사용자 정의 카테고리: 할일 미연결 시만 삭제 가능
- 할일 연결된 카테고리 삭제 시도: 409 Conflict

### 비밀번호 정책
- 최소 길이: 8자 이상
- 특수문자/대소문자 혼합 권장 (1차는 길이만 검증)
- 변경 시 bcrypt 해싱 처리

### 할일 완료 토글
- 미완료 → 완료: 체크박스 체크, strikethrough 표시, opacity 감소
- 완료 → 미완료: 체크박스 해제, strikethrough 제거, opacity 복원
- 완료 상태에서도 수정/삭제 가능 (BR-06)
