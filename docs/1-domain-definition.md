## 1. 프로젝트 개요

### 배경

- 개인 단위의 할일을 체계적으로 관리할 수 있는 전용 애플리케이션이 부재하다.
- 인증된 사용자별로 데이터를 분리 저장하는 할일 관리 솔루션이 없다.
- 카테고리 기반의 할일 분류 및 필터링 기능을 제공하는 앱이 없다.

### 목적

인증된 사용자가 자신만의 할일을 카테고리별로 등록·관리하고, 다양한 조건으로 필터링하여 개인 생산성을 높이는 웹 애플리케이션을 제공한다.

## 2. 도메인 모델

### 2.1 핵심 엔티티

#### User (사용자)

| 속성      | 타입     | 설명                   |
| --------- | -------- | ---------------------- |
| id        | UUID     | 사용자 고유 식별자     |
| email     | String   | 로그인 이메일 (유일값) |
| password  | String   | 암호화된 비밀번호      |
| name      | String   | 사용자 이름            |
| createdAt | DateTime | 가입일시               |
| updatedAt | DateTime | 정보 수정일시          |

#### Todo (할일)

| 속성        | 타입     | 설명                       |
| ----------- | -------- | -------------------------- |
| id          | UUID     | 할일 고유 식별자           |
| userId      | UUID     | 소유자 (User 외래키)       |
| categoryId  | UUID     | 카테고리 (Category 외래키) |
| title       | String   | 할일 제목                  |
| description | String   | 할일 설명                  |
| dueDate     | Date     | 종료 예정일                |
| isCompleted | Boolean  | 완료 여부 (기본값: false)  |
| createdAt   | DateTime | 등록일시                   |
| updatedAt   | DateTime | 수정일시                   |

#### Category (카테고리)

| 속성      | 타입    | 설명                                       |
| --------- | ------- | ------------------------------------------ |
| id        | UUID    | 카테고리 고유 식별자                       |
| userId    | UUID    | 소유자 (User 외래키, 기본 카테고리는 null) |
| name      | String  | 카테고리명                                 |
| isDefault | Boolean | 기본 카테고리 여부                         |

### 2.2 엔티티 관계

```
User 1 ──── N Todo
User 1 ──── N Category (사용자 정의 카테고리)
Category 1 ──── N Todo
```

## 3. 핵심 비즈니스 규칙

### 인증 규칙

- BR-01: 사용자는 회원가입 후 이메일/비밀번호 인증을 통해서만 앱을 이용할 수 있다.
- BR-02: 인증된 사용자만 할일 및 카테고리 데이터에 접근할 수 있다.
- BR-03: 사용자는 자신의 데이터(할일, 카테고리, 개인정보)만 조회·수정·삭제할 수 있다.

### 할일 규칙

- BR-04: 할일 등록 시 제목(title)과 카테고리(category)는 필수 입력값이다.
- BR-05: 할일의 종료 예정일(dueDate)은 선택 입력값이다.
- BR-06: 할일 완료 처리 후에도 수정 및 완료 취소가 가능하다.

### 카테고리 규칙

- BR-07: 시스템은 모든 사용자에게 공통으로 적용되는 기본 카테고리를 제공한다.
- BR-08: 인증된 사용자는 기본 카테고리 외에 사용자 정의 카테고리를 추가할 수 있다.
- BR-09: 사용자 정의 카테고리는 해당 사용자만 사용할 수 있다.
- BR-10: 할일이 연결된 카테고리는 삭제할 수 없다.

### 개인정보 규칙

- BR-11: 인증된 사용자는 자신의 이름, 비밀번호 등 개인정보를 수정할 수 있다.
- BR-12: 이메일은 사용자 식별자로 사용되며 변경할 수 없다.

## 4. 주요 유스케이스

| ID    | 유스케이스     | 액터          | 설명                                                                     |
| ----- | -------------- | ------------- | ------------------------------------------------------------------------ |
| UC-01 | 회원가입       | 비인증 사용자 | 이메일, 비밀번호, 이름을 입력하여 계정을 생성한다.                       |
| UC-02 | 로그인         | 비인증 사용자 | 이메일/비밀번호로 인증하고 세션(토큰)을 발급받는다.                      |
| UC-03 | 개인정보 수정  | 인증된 사용자 | 이름, 비밀번호 등 개인정보를 수정한다.                                   |
| UC-04 | 할일 등록      | 인증된 사용자 | 제목, 설명, 종료 예정일, 카테고리를 입력하여 할일을 생성한다.            |
| UC-05 | 할일 수정      | 인증된 사용자 | 등록된 할일의 정보를 수정한다.                                           |
| UC-06 | 할일 삭제      | 인증된 사용자 | 등록된 할일을 삭제한다.                                                  |
| UC-07 | 할일 완료 처리 | 인증된 사용자 | 할일의 완료 여부를 변경한다.                                             |
| UC-08 | 할일 목록 조회 | 인증된 사용자 | 카테고리, 종료 기간, 완료 여부 조건으로 필터링하여 할일 목록을 조회한다. |
| UC-09 | 카테고리 추가  | 인증된 사용자 | 사용자 정의 카테고리를 추가한다.                                         |
| UC-10 | 카테고리 삭제  | 인증된 사용자 | 할일이 연결되지 않은 사용자 정의 카테고리를 삭제한다.                    |

## 5. 용어 사전

| 용어                             | 정의                                                                         |
| -------------------------------- | ---------------------------------------------------------------------------- |
| 사용자 (User)                    | 회원가입을 완료하고 인증을 통해 앱을 이용하는 개인                           |
| 인증 (Authentication)            | 이메일과 비밀번호를 통해 사용자 신원을 확인하는 과정                         |
| 할일 (Todo)                      | 사용자가 수행해야 할 작업 단위. 제목, 설명, 종료 예정일, 카테고리로 구성됨   |
| 종료 예정일 (Due Date)           | 할일을 완료해야 하는 목표 날짜                                               |
| 완료 여부 (isCompleted)          | 할일의 수행 완료 상태를 나타내는 플래그                                      |
| 카테고리 (Category)              | 할일을 분류하기 위한 그룹 단위                                               |
| 기본 카테고리 (Default Category) | 시스템이 사전에 정의하여 모든 사용자에게 공통 제공하는 카테고리              |
| 사용자 정의 카테고리             | 인증된 사용자가 직접 생성한 카테고리. 해당 사용자에게만 표시됨               |
| 필터링 (Filtering)               | 할일 목록 조회 시 카테고리, 종료 기간, 완료 여부 조건으로 목록을 좁히는 기능 |
