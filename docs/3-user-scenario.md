## 정상 흐름 시나리오

### SCN-01 신규 계정 생성

- **페르소나**: 김민준
- **관련 UC**: UC-01
- **상황**: 김민준은 메모앱에 흩어진 할일을 하나로 통합하고 싶어 TodoListApp을 처음 방문했다. 아직 계정이 없다.
- **행동**:
  1. 회원가입 화면(SCR-01)에서 이메일, 비밀번호(8자 이상), 이름을 입력한다.
  2. "가입하기" 버튼을 클릭한다.
  3. 시스템이 입력값 유효성을 검사하고 이메일 중복 여부를 확인한다.
  4. 비밀번호를 해시 처리하여 계정을 생성한다.
- **결과**: 계정 생성 완료 메시지가 표시되고, 로그인 화면으로 이동한다. 이후 해당 이메일로 로그인이 가능해진다.

---

### SCN-02 로그인 및 JWT 발급

- **페르소나**: 김민준
- **관련 UC**: UC-02
- **상황**: 김민준은 가입 후 처음으로 로그인한다.
- **행동**:
  1. 로그인 화면(SCR-02)에서 가입한 이메일과 비밀번호를 입력한다.
  2. "로그인" 버튼을 클릭한다.
  3. 시스템이 이메일/비밀번호를 검증한다.
- **결과**: JWT Access Token이 발급되고, 할일 목록 화면(SCR-03)으로 이동한다. 이후 인증이 필요한 모든 기능을 사용할 수 있다.

---

### SCN-03 이름 변경

- **페르소나**: 김민준
- **관련 UC**: UC-03
- **상황**: 김민준은 앱에서 표시되는 이름을 닉네임 형식으로 변경하고 싶다.
- **행동**:
  1. 내 정보 수정 화면(SCR-06)으로 이동한다.
  2. 이름 필드에 새로운 이름을 입력한다.
  3. "저장" 버튼을 클릭한다.
- **결과**: 이름이 즉시 업데이트된다. 이메일 필드는 수정 불가 상태로 표시된다.

---

### SCN-04 새 할일 등록 (마감일 포함)

- **페르소나**: 이수진
- **관련 UC**: UC-04
- **상황**: 이수진은 오전에 팀장으로서 오늘 처리해야 할 업무 보고서 작성 건을 등록하려 한다. 마감일이 오늘이다.
- **행동**:
  1. 할일 등록 폼(SCR-04)을 연다.
  2. 제목에 "팀 주간 업무 보고서 작성"을 입력한다.
  3. 카테고리를 "업무"로 선택한다.
  4. 마감일(dueDate)을 오늘 날짜로 설정한다.
  5. "등록" 버튼을 클릭한다.
- **결과**: 할일이 `isCompleted=false` 상태로 생성된다. 목록 화면에서 등록일 기준 최상단에 해당 할일이 표시된다.

---

### SCN-05 할일 내용 수정

- **페르소나**: 김민준
- **관련 UC**: UC-05
- **상황**: 김민준은 전날 등록한 할일의 마감일이 하루 연장되어 날짜를 수정해야 한다.
- **행동**:
  1. 할일 목록에서 해당 항목을 선택해 수정 폼(SCR-04)을 연다.
  2. 종료 예정일(dueDate)을 하루 뒤로 변경한다.
  3. "저장" 버튼을 클릭한다.
- **결과**: 변경된 마감일이 저장되고, 목록에서 수정된 내용이 즉시 반영된다.

---

### SCN-06 완료된 할일 삭제

- **페르소나**: 김민준
- **관련 UC**: UC-06
- **상황**: 김민준은 완료 처리된 오래된 할일들을 정리하여 목록을 깔끔하게 유지하고 싶다.
- **행동**:
  1. 할일 목록에서 삭제할 항목을 선택한다.
  2. 삭제 버튼을 클릭하고 확인 대화상자에서 삭제를 승인한다.
- **결과**: 해당 할일이 목록에서 즉시 제거된다.

---

### SCN-07 할일 완료 체크

- **페르소나**: 이수진
- **관련 UC**: UC-07
- **상황**: 이수진은 모바일로 이동 중 방금 완료한 업무 보고서 작성 건을 완료 처리하려 한다.
- **행동**:
  1. 할일 목록(SCR-03)에서 완료한 항목의 체크박스를 탭한다.
- **결과**: `isCompleted` 값이 `true`로 토글된다. 완료 상태로 시각적으로 구분 표시된다. 이후 수정이나 완료 취소도 가능한 상태를 유지한다.

---

### SCN-08 마감일 임박 할일 필터링 조회

- **페르소나**: 이수진
- **관련 UC**: UC-08
- **상황**: 이수진은 점심시간에 모바일로 이번 주 마감 예정인 미완료 할일만 빠르게 확인하고 싶다.
- **행동**:
  1. 할일 목록 화면(SCR-03)에서 필터를 설정한다.
  2. 종료 기간을 오늘부터 이번 주 금요일까지로 지정한다.
  3. 완료 여부 필터를 "미완료"로 선택한다.
  4. 필터 적용 버튼을 탭한다.
- **결과**: 이번 주 마감이면서 미완료 상태인 본인 할일만 등록일 내림차순으로 표시된다. 타 사용자의 할일은 포함되지 않는다.

---

### SCN-09 사용자 정의 카테고리 추가

- **페르소나**: 김민준
- **관련 UC**: UC-09
- **상황**: 김민준은 사이드 프로젝트 관련 할일을 별도로 분류하기 위해 "사이드프로젝트" 카테고리를 만들고 싶다.
- **행동**:
  1. 카테고리 관리 화면(SCR-05)으로 이동한다.
  2. 카테고리명 입력란에 "사이드프로젝트"를 입력한다.
  3. "추가" 버튼을 클릭한다.
- **결과**: `isDefault=false`, `userId=김민준` 으로 카테고리가 생성된다. 해당 카테고리는 김민준의 할일 등록 폼에서만 선택 가능하다.

---

### SCN-10 빈 카테고리 삭제

- **페르소나**: 김민준
- **관련 UC**: UC-10
- **상황**: 김민준은 더 이상 사용하지 않는 "사이드프로젝트" 카테고리를 삭제하려 한다. 해당 카테고리에 연결된 할일은 없다.
- **행동**:
  1. 카테고리 관리 화면(SCR-05)에서 "사이드프로젝트" 카테고리 옆 삭제 버튼을 클릭한다.
  2. 확인 대화상자에서 삭제를 승인한다.
- **결과**: 카테고리가 즉시 삭제되고 목록에서 사라진다.

---

### SCN-11 회원 탈퇴

- **페르소나**: 김민준
- **관련 UC**: UC-11
- **상황**: 김민준은 앱을 더 이상 사용하지 않기로 결정하고 계정과 모든 데이터를 삭제하고 싶다.
- **행동**:
  1. 내 정보 수정 화면(SCR-06)에서 "회원 탈퇴" 버튼을 클릭한다.
  2. 탈퇴 확인 대화상자에서 "탈퇴" 버튼을 클릭한다.
- **결과**: 사용자 계정 및 연관 데이터(할일, 사용자 정의 카테고리)가 즉시 삭제(CASCADE DELETE)된다. 보유 중이던 JWT는 즉시 무효 처리되고 로그인 화면으로 이동한다.

## 예외 흐름 시나리오

### SCN-12 중복 이메일로 회원가입 시도

- **페르소나**: 김민준
- **관련 UC**: UC-01
- **상황**: 김민준이 이미 가입된 이메일로 다시 회원가입을 시도한다.
- **행동**:
  1. 회원가입 화면(SCR-01)에서 기존에 사용 중인 이메일, 비밀번호, 이름을 입력한다.
  2. "가입하기" 버튼을 클릭한다.
- **결과**: 시스템이 409 Conflict 응답을 반환한다. "이미 사용 중인 이메일입니다" 오류 메시지가 화면에 표시된다. 계정은 생성되지 않는다.

---

### SCN-13 유효하지 않은 비밀번호로 회원가입 시도

- **페르소나**: 이수진
- **관련 UC**: UC-01
- **상황**: 이수진이 편의상 짧은 비밀번호(4자)를 입력하여 가입을 시도한다.
- **행동**:
  1. 회원가입 화면(SCR-01)에서 이메일, 이름은 정상 입력하고 비밀번호를 4자로 입력한다.
  2. "가입하기" 버튼을 클릭한다.
- **결과**: 시스템이 400 Bad Request 응답을 반환한다. "비밀번호는 최소 8자 이상이어야 합니다" 유효성 오류 메시지가 표시된다.

---

### SCN-14 존재하지 않는 계정으로 로그인 시도

- **페르소나**: 이수진
- **관련 UC**: UC-02
- **상황**: 이수진이 오타로 인해 가입하지 않은 이메일을 입력하여 로그인을 시도한다.
- **행동**:
  1. 로그인 화면(SCR-02)에서 미가입 이메일과 비밀번호를 입력한다.
  2. "로그인" 버튼을 클릭한다.
- **결과**: 시스템이 401 Unauthorized 응답을 반환한다. "이메일 또는 비밀번호가 올바르지 않습니다" 오류 메시지가 표시된다. 로그인되지 않는다.

---

### SCN-15 비밀번호 불일치로 로그인 실패

- **페르소나**: 김민준
- **관련 UC**: UC-02
- **상황**: 김민준이 가입한 이메일은 맞지만 비밀번호를 잘못 입력한다.
- **행동**:
  1. 로그인 화면(SCR-02)에서 올바른 이메일과 잘못된 비밀번호를 입력한다.
  2. "로그인" 버튼을 클릭한다.
- **결과**: 시스템이 401 Unauthorized 응답을 반환한다. 오류 메시지가 표시되고 로그인되지 않는다.

---

### SCN-16 JWT 만료 상태에서 개인정보 수정 시도

- **페르소나**: 이수진
- **관련 UC**: UC-03
- **상황**: 이수진의 JWT가 만료된 상태에서 비밀번호 변경을 시도한다.
- **행동**:
  1. 내 정보 수정 화면(SCR-06)에서 새 비밀번호를 입력한다.
  2. "저장" 버튼을 클릭한다.
- **결과**: 시스템이 401 Unauthorized 응답을 반환한다. 수정이 처리되지 않고, 로그인 화면으로 리다이렉트된다.

---

### SCN-17 필수값 누락으로 할일 등록 실패

- **페르소나**: 이수진
- **관련 UC**: UC-04
- **상황**: 이수진이 급하게 할일을 등록하다가 카테고리 선택을 빠뜨린 채 등록 버튼을 누른다.
- **행동**:
  1. 할일 등록 폼(SCR-04)에서 제목만 입력하고 카테고리를 선택하지 않는다.
  2. "등록" 버튼을 클릭한다.
- **결과**: 시스템이 400 Bad Request 응답을 반환한다. "카테고리를 선택해 주세요" 오류 메시지가 표시된다. 할일은 생성되지 않는다.

---

### SCN-18 타인 할일 수정 시도

- **페르소나**: 김민준
- **관련 UC**: UC-05
- **상황**: 김민준이 직접 API를 호출하는 방식으로 타인 소유의 할일 ID를 이용해 수정을 시도한다.
- **행동**:
  1. 본인 소유가 아닌 할일 ID로 PATCH `/api/todos/:id` 요청을 보낸다.
- **결과**: 시스템이 403 Forbidden 응답을 반환한다. 수정은 처리되지 않는다.

---

### SCN-19 존재하지 않는 할일 삭제 시도

- **페르소나**: 김민준
- **관련 UC**: UC-06
- **상황**: 김민준이 이미 삭제된 할일을 다시 삭제하려 한다(새로고침 누락 등 UI 동기화 지연 상황).
- **행동**:
  1. 목록에서 해당 항목의 삭제 버튼을 클릭한다.
- **결과**: 시스템이 404 Not Found 응답을 반환한다. "존재하지 않는 할일입니다" 오류 메시지가 표시된다.

---

### SCN-20 타인 할일 완료 처리 시도

- **페르소나**: 이수진
- **관련 UC**: UC-07
- **상황**: 이수진이 타인 소유의 할일 ID로 완료 토글 API를 호출한다.
- **행동**:
  1. 본인 소유가 아닌 할일 ID로 PATCH `/api/todos/:id/complete` 요청을 보낸다.
- **결과**: 시스템이 403 Forbidden 응답을 반환한다. 완료 처리는 이루어지지 않는다.

---

### SCN-21 중복 카테고리명 추가 시도

- **페르소나**: 김민준
- **관련 UC**: UC-09
- **상황**: 김민준이 이미 생성한 "사이드프로젝트" 카테고리와 동일한 이름으로 또 추가를 시도한다.
- **행동**:
  1. 카테고리 관리 화면(SCR-05)에서 카테고리명에 "사이드프로젝트"를 입력한다.
  2. "추가" 버튼을 클릭한다.
- **결과**: 시스템이 409 Conflict 응답을 반환한다. "이미 존재하는 카테고리명입니다" 오류 메시지가 표시된다.

---

### SCN-22 할일이 연결된 카테고리 삭제 시도

- **페르소나**: 김민준
- **관련 UC**: UC-10
- **상황**: 김민준이 "업무" 카테고리를 삭제하려 하지만 해당 카테고리에 연결된 할일이 3건 존재한다.
- **행동**:
  1. 카테고리 관리 화면(SCR-05)에서 "업무" 카테고리 옆 삭제 버튼을 클릭한다.
- **결과**: 시스템이 409 Conflict 응답을 반환한다. "해당 카테고리에 연결된 할일이 있어 삭제할 수 없습니다" 오류 메시지가 표시된다. 카테고리는 삭제되지 않는다.

---

### SCN-23 기본 카테고리 삭제 시도

- **페르소나**: 이수진
- **관련 UC**: UC-10
- **상황**: 이수진이 시스템 제공 기본 카테고리를 삭제하려 시도한다.
- **행동**:
  1. 카테고리 관리 화면(SCR-05)에서 기본 카테고리(isDefault=true)의 삭제 버튼을 클릭한다.
- **결과**: 시스템이 403 Forbidden 응답을 반환한다. "기본 카테고리는 삭제할 수 없습니다" 오류 메시지가 표시된다.

### SCN-24 미인증 상태에서 회원 탈퇴 시도

- **페르소나**: 이수진
- **관련 UC**: UC-11
- **상황**: 이수진의 JWT가 만료된 상태에서 회원 탈퇴 API 요청이 전송된다.
- **행동**:
  1. 유효하지 않은 JWT로 DELETE `/api/users/me` 요청을 보낸다.
- **결과**: 시스템이 401 Unauthorized 응답을 반환한다. 탈퇴는 처리되지 않는다.
